# Code of Conduct

We want this project to be a respectful, curious place for learning. Be kind,
assume good intent, welcome different experience levels, and focus criticism on
ideas and artifacts rather than people.

Harassment, discrimination, intimidation, personal attacks, and sharing other
people's private information are not acceptable.

Maintainers will review reports, may remove content or participation that
violates these standards, and will handle reports as discreetly as practical.
Report conduct concerns through a private GitHub security advisory with enough
context for maintainers to assess the situation. Do not include credentials or
unnecessary personal data.

# Security Policy

If you discover a potential vulnerability, please report it through a **private GitHub security advisory** for this repository. This keeps the report out of the public issue tracker while maintainers assess it.

Provide a clear description, affected area, safe reproduction steps, and impact
assessment. Do not include credentials, API keys, access tokens, private URLs,
or personal data. Use redacted or fictional examples whenever possible.

Please do not open a public issue for a suspected vulnerability. We do not
publish a response-time or remediation SLA; maintainers will evaluate reports
in good faith and coordinate next steps through the advisory.

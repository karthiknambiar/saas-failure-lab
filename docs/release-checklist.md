# Release checklist

Use this checklist only after a repository owner approves release work.

- [ ] CI is green for the intended commit, including formatting, linting,
      tests, and the production build.
- [ ] Public docs and media have been reviewed for accuracy and no confidential
      data, credentials, private URLs, production identifiers, personal data, or
      customer information.
- [ ] A repository owner has enabled GitHub Pages in the appropriate Pages
      settings and approved the selected deployment trigger.
- [ ] The first deployment URL has been reviewed: landing page, scenario
      browser, an investigation, and a completed-share flow work from the deployed
      repository base path.
